# balpom/types
## Simple library for work with PHP types.

Simple library for type checking and type casting.

### Requirements 
- **PHP >= 8.2**


### Usage
Simple add it as a dependency to the "require" section in composer.json file, similar to:
```bash
"require": {
    "balpom/types": "*"
}
```
and then run:
```
composer dumpautoload
```
